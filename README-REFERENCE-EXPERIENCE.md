# Cruzen Digital – reference-inspired experience update

This update expands the existing React + Vite website with reference-inspired digital-marketing content and motion while retaining the Pearl White + Lavender Purple theme.

## Added routes
- `/growth-plan` – scroll-led four-stage growth roadmap with a scroll-position rocket rail.
- `/free-growth-audit` – three-step audit enquiry UI.
- `/contact` – contact enquiry form UI.
- `/team` – capability/team section.
- `/blog` – digital marketing insight cards and FAQ accordion.
- `/consult` and `/ai-audit` route to the audit form.
- `/login` currently routes to contact; it is not an authentication system.

## Homepage additions
- Growth positioning section
- Creative/video showcase concept (not a hosted video player)
- Portfolio-category cards
- Client-experience quote placeholder (replace with an approved, real testimonial)
- Service-area chips
- Channel shortcuts and audit/consultation CTA

## Important production notes
- Audit and contact forms are front-end demonstrations. Connect to an approved API/CRM/email service before accepting real submissions.
- Portfolio cards are illustrative categories, not verified client case studies or performance claims.
- Replace the testimonial placeholder with a real approved review before publishing.
- Install dependencies with `npm install`, then run `npm run dev` and `npm run build`.
